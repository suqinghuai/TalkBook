功能

为一个需求而生的完整导出方案

从取密钥到出归档，语册把「导出微信聊天记录」整条链路做成一个桌面程序。

本地解密，离线运行

直接解密本地微信 4.x 数据库，不依赖微信在线，断网也能导出。

三种归档格式

导出 TXT / JSON / HTML 归档，聊天、语音、图片与头像在本地完整还原。

获取密钥已内置

内置 V4 内存扫描与 Hook 注入两种取密钥方式，不必额外安装脚本。

定时自动导出

为指定联系人或群设置间隔，自动增量导出到目标文件夹，带完整运行日志。

语音转文字

对导出的 HTML 归档调用大模型把语音转成文字并写回，断点续跑不丢进度。

联系人统计

汇总每个会话的消息 / 语音 / 图片数量，支持多选批量导出与本地头像还原。

数据只属于你，不出本机

语册的解密、解析与导出全部在本地完成，不向任何外部网络发送聊天内容。语音转文字时，仅语音片段会发送到你自行配置的大模型接口，其余记录全程留在本机。

使用流程

四步，拿到归档

全程本地操作，遇到任何一步都有清晰提示与反馈。

第 1 步

获取解密密钥

内置 V4 内存扫描或 Hook 注入两种方式，在侧边栏一键触发，密钥自动保存。

第 2 步

选择会话

浏览联系人或群聊，查看各自消息 / 语音 / 图片统计，多选批量导出。

第 3 步

导出归档

选择 TXT / JSON / HTML 格式与时间范围，图片、语音、头像在本地一并还原。

第 4 步

查看 / 语音转写

在浏览器打开 HTML 归档即可回看；需要时对语音调用大模型转成文字并写回。
