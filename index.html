功能

一份聊天，多种用途

多格式导出、语音转文字、数据可视化一应俱全，把微信聊天记录变成可回顾、可备份、可取证的个人档案。

多格式导出

支持 TXT / JSON / HTML 归档，也可导出为 PDF，图片、语音、头像在本地完整还原。

语音转文字

对导出的归档调用大模型把语音转成文字并写回，断点续跑不丢进度，回看更省心。

数据可视化

把消息量、语音、图片等整理成图表，一眼看清每段关系的沟通节奏与重点。

本地解密，数据不上传

解密与解析完全在本地运行、数据不上传，仅在需要时联网验证，聊天内容不出本机。

定时自动导出

为指定联系人或群设置间隔，自动增量导出到目标文件夹，带完整运行日志。

导出用于纪念·备份·取证

导出的档案是个人纪念册，也是可靠的数据备份，关键对话更可作为法律取证材料。

解密本地运行，数据不上传

语册的解密与数据解析完全在本地完成，聊天内容不向任何外部网络上传。软件仅在你配置的大模型语音转写、或联网验证时产生网络请求，其余处理全程留在本机。

使用流程

四步，拿到你的档案

从取密钥到导出 PDF / 语音转文字，全程有清晰提示与反馈。

第 1 步

获取解密密钥

内置 V4 内存扫描或 Hook 注入两种方式，在侧边栏一键触发，密钥自动保存。

第 2 步

选择会话

浏览联系人或群聊，查看各自消息 / 语音 / 图片统计与可视化盘点，多选批量导出。

第 3 步

导出归档 / PDF

选择 TXT / JSON / HTML / PDF 格式与时间范围，图片、语音、头像在本地一并还原。

第 4 步

回看 / 语音转写

在浏览器打开 HTML 归档即可回看；需要时对语音调用大模型转成文字并写回。
