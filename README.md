# TalkBook（语册）

> **当前版本：v3.5.0 · 2026-10-07**（上一版 v3.2.0）

> **语册（TalkBook）· 微信 4.x 聊天记录本地导出工具** —— 桌面窗口 / 本地 WebUI 浏览与导出（TXT / JSON / HTML 归档），获取密钥已内置，并支持定时自动导出、**语音转文字**与**转 PDF**。
> 全部数据的解密、解析与导出都在本机完成，**不向任何外部网络发送数据**（语音转文字仅需用户自行配置的大模型接口，其余聊天内容不出本机）。

TalkBook 整合了早期三个独立脚本（`legacy/TalkBook_getkey`、`legacy/TalkBook_decrypt`、`legacy/TalkBook_media`），并参考开源项目 [WeChatDataAnalysis-main](../../WeChatDataAnalysis-main) 对微信 4.x 数据库结构的研究成果，形成 **「单一工具」** —— 获取密钥已并入导出程序：

```
┌──────────────────────────────────────────────────────────────┐
│              TalkBook（语册）—— 微信聊天记录导出工具              │
│   TalkBook-导出.exe（桌面窗口 + 浏览器 WebUI 双入口）             │
│                                                              │
│   · 侧边栏导航：聊天 / 联系人 / 自动导出 / 语音转文字 / 转 PDF / 订阅会员 / 获取密钥 / 设置 / 关于  │
│   · 获取密钥已内置：方式一 V4 内存扫描 / 方式二 Hook 注入          │
│   · 按需解密 + 增量更新 + 缓存复用                             │
│   · 联系人统计（消息 / 语音 / 图片数）                          │
│   · 导出 TXT / JSON / HTML 归档                               │
│   · 定时自动导出（指定会话增量）                               │
│   · 语音转文字（对导出的 HTML 归档调用大模型转写并写回，断点续跑）   │
│   · 转 PDF（对导出的 HTML 按消息数拆分后批量调用 Edge 转 PDF）     │
│   · 图片 / 语音 / 头像 本地还原（自动获取本账号头像）             │
│        共享解密核心 core/wcdb.py · imagekey.py · config.py     │
└──────────────────────────────────────────────────────────────┘
```

| 入口（源码） | 打包 exe | 形式 |
|------------|----------|------|
| `uv run talkbook-desktop` / `uv run talkbook-webui` | `TalkBook-导出.exe` | 桌面窗口（默认）+ 浏览器 WebUI |

### v1.2.3 · 2026-10-05
本次升级聚焦**图片原图导出能力**（参考开源项目 WeChatDataAnalysis 的多目录索引思路改造）：

- **新增「扫描原图」导出选项**：导出弹窗「导出内容」区新增 `扫描原图（勾选后优先取本地原图，较慢）` 复选框。默认不勾选，仍按原模式从 `msg/attach` 取图（快、多为缩略图）；勾选后才启用全盘原图搜索。
- **全盘原图搜索（`MediaResolver._build_original_index` / `resolve_original`）**：在 `msg/attach` 之外，额外扫描 `cache/<日期>/…`、`msg/video / msg/file / msg/media / msg/image`、`business/favorite` 等目录，把所有 `<md5>.dat` / `<md5>_h.dat` 等变体收集进索引；同一 md5 出现多个变体时按 `_RANK`（无后缀原图 > `_h` 高清 > `_b` > `_c` > `_t` 缩略图）**择优取原图 / 高清图**，找不到再回退 `msg/attach` 快索引。
- **懒加载 + 可开关**：原图索引仅当导出勾选「扫描原图」时才构建（线程安全、构建一次缓存），不勾选时零额外开销，导出速度不受影响。
- **贯通导出链路**：`export_html(..., use_original)`、WebUI 单聊导出与批量导出的 `_run_export_single` / `_run_export_task` / `/api/export` 均支持 `use_original` 参数；自定义表情 `read_emoji` / `find_emoji_local` 的图片兜底同样走原图优先。
- 实证：真实账号 `msg/attach` 有 9009 个图片 md5，其中 5478 个本地仅缓存缩略图（`_t`）；启用扫描原图后，能在 cache / favorite 等位置捞回部分散落原图（如 3.7KB 缩略图提升到 65KB 原图）；本地从未下载过原图的消息仍保持缩略图（微信本身没有该原图文件，任何工具都无法还原）。

## 软件授权说明

TalkBook 两个 exe 均内置**一次性激活码 + 硬件绑定**的授权机制，未激活时无法使用核心功能。

### 授权码格式与有效期

- 授权码为 **16 位数字、4 组**：`XXXX-XXXX-XXXX-XXXX`
- **每日变化**：授权码由当天日期计算而来，只有当天日期对应的授权码才能通过校验
  - 第 1 组 = `yyyyMMdd × 1037`（补 0 到 8 位）的**前 4 位**
  - 第 3 组 = `yyyyMMdd × 1037`（补 0 到 8 位）的**后 4 位**
  - 第 2 组 = `MMdd × 108`（补 0 到 4 位）的**前 4 位**
  - 第 4 组 = **任意** 4 位数字（仅掩人耳目，不参与校验）
- 校验只核对第 1、2、3 组；第 4 组可任意填写。

> 例：以 `2026-10-04` 为例，`20261004 × 1037 = 21010661148` → 前 4 位 `2101`、后 4 位 `1148`；`1004 × 108 = 108432` → 前 4 位 `1084`。当天合法授权码形如 `2101-1084-1148-xxxx`（末组任意）。

### 激活方式

- **获取密钥 exe（命令行）**：启动时若未激活，会在命令行上方显示技术支持信息并提示「请输入授权码」，输入当天有效授权码即可激活；激活后继续正常获取密钥。
- **导出 exe（WebUI）**：打开浏览器后若未激活，会先显示**授权激活界面**，输入授权码激活（成功后给出明确反馈并自动进入软件），之后即可使用聊天 / 联系人 / 配置等全部功能。

### 激活文件与免激活

- 激活成功后，软件会自动在**缓存目录**下新建 `important` 文件夹，并写入一个以 **CPU序列号_硬盘序列号** 命名的 `.lic` 文件（如 `BFEBFBFF000806EA_002839300B97.lic`），文件内容记录激活日期。
- 之后每次运行，软件自动扫描该目录：若存在与当前硬件指纹匹配的 `.lic` 文件，即视为已激活，**直接运行，无需再次输入授权码**。
- 授权文件只在本机本地生成，**不联网**；换机后需重新激活（指纹不同）。

### 技术支持

需要获取授权码、遇到问题或需要定制，请联系**技术支持 v：dawn10370108**。

## 获取密钥（已合并进导出工具）

获取密钥功能已并入导出程序（桌面窗口 / WebUI），**不再提供独立的「获取密钥」程序与命令行入口**。在**左侧边栏「获取密钥」视图**可直接触发两种方式：

- **方式一 · V4 内存扫描（推荐）**：从已登录微信进程内存与 `Weixin.dll` 提取数据库密钥，自动校验并写入 `config.ini`，无需重新登录。
- **方式二 · Hook 注入**：向微信进程注入 `wx_key.dll`，退出并重新登录微信后在登录瞬间截获密钥（最长等待 120 秒）。

两种方式都会同时解析图片密钥（`image_xor_key / image_aes_key`）并写入 `config.ini`。核心实现位于 `core/keystore.py`，由 `server/api.py` 提供 `/api/getkey/*` 接口；数据库路径含中文时会提示「请更改到全英文目录后重试」。

## 导出聊天记录（桌面窗口 + WebUI）详解

导出程序有**两种入口**（同一套 FastAPI 后端 + 前端，代码在 `server/`）：

- **桌面窗口（默认）**：`uv run talkbook-desktop` / `TalkBook-导出.exe`。pywebview 无边框窗口 + 自定义标题栏 + 侧边栏导航，参考 Electron 风格。
- **浏览器 WebUI**：`uv run talkbook-webui`。在浏览器打开 `http://127.0.0.1:8000`（适合多端访问 / 远程）。

### 启动参数

```bash
uv run talkbook-desktop                # 桌面窗口（默认入口；打包 exe 双击即此形式）
uv run talkbook-webui                  # 浏览器 WebUI，默认 http://127.0.0.1:8000，自动打开浏览器
uv run talkbook-webui --port 9000      # 指定端口
uv run talkbook-webui --no-browser     # 不自动打开浏览器（适合远程/脚本）
```

> 若尚未授权激活，桌面窗口 / 浏览器打开后先显示**授权激活界面**（输入 16 位授权码 `XXXX-XXXX-XXXX-XXXX`，激活成功有明确反馈并自动进入软件）；已激活则直接进入主界面。主界面右上角与激活页均显示「技术支持v：dawn10370108」。

### 解密管理模式（核心）

本板块采用**按需解密**设计，兼顾启动速度与数据安全：

- **默认不解密消息**：首次进入只解密「联系人列表」（contact 库），消息库保持不解密，因此启动飞快、可立即搜索/查看联系人。
- **开始解密**：在「设置」页点击「开始解密」，后台自动解密全部消息库（`message_N.db` / `media_N.db`），完成后即可浏览、搜索与导出聊天记录。
- **缓存复用**：解密产物写入本程序目录的 `cache/`。源数据库文件（大小 + 修改时间）未变时，每次启动**直接沿用缓存，不再重复解密**。
- **增量更新**：聊天有新消息（源库有变化）时，在设置页点「增量更新」，只对新增/变化的库做增量解密，秒级完成。
- **重新解密 / 刷新数据库 / 清除缓存**：当需要强制重扫或清空缓存时使用（清除后回到未解密状态）。

### 界面：侧边栏导航

左侧侧边栏（图标左文字右）提供 **聊天 / 联系人 / 自动导出 / 语音转文字 / 转 PDF / 订阅会员 / 获取密钥 / 设置 / 关于** 九个视图（桌面窗口与 WebUI 一致）：

- **聊天**：会话列表（左侧）+ 聊天窗口（右侧）
  - 会话列表：全部单聊/群聊，已解密时**按最近消息时间倒序**排列（与微信会话列表一致，最新活跃的会话在最前）并显示最后消息预览与时间；**未解密时只显示联系人并标注「未解密」**；顶部支持名称/账号搜索
  - 聊天浏览：微信风格气泡、按天分组、**无限上滑**加载更早消息、会话内关键词搜索
    - 文本 / 引用 / 系统消息 / 文件链接：完整渲染
    - 语音：**直接在线播放**（SILK → WAV 实时转换）
    - 图片/表情：图片用图片密钥解密 V2 `*.dat`；表情分两类——**内置文字表情码**映射为微信自带图标、**自定义表情包**本地缓存还原或远程 AES 解密，预览与导出均显示真实图片
    - 头像：从本地 `head_image.db` 提取各发送者头像，圆形渲染在气泡旁；**本账号头像自动从微信数据目录还原**，无需手动填写
- **联系人**：**联系人统计列表**，表格展示每个联系人的**消息数 / 语音数 / 图片数**（已解密时实时统计，未解密时显示 `—` 并提示「消息未解密，统计暂不可用」）；支持搜索
- **自动导出**：定时自动导出模块（见下）
- **语音转文字**：对导出的 HTML 归档调用大模型转写语音并写回（见下）
- **转 PDF**：对导出的 HTML 归档按消息数拆分后批量调用 Edge 转 PDF（见下）
- **订阅会员**：会员页面（「会员功能暂未开放，无需付费」+ 收款码）
- **获取密钥**：在界面内触发获取密钥（方式一 V4 内存扫描 / 方式二 Hook 注入），无需切到命令行
- **设置**：配置 + 解密管理（见下）
- **关于**：软件名称 / 当前版本 / 官网（点击直接跳转）

## 技术实现要点

- **数据库解密**：`core/wcdb.py` 实现 sqlitecipher4 整库解密，按源文件大小/时间戳做磁盘缓存，重复打开秒级完成
- **按需解密**：导出模块默认只解密联系人、不解密消息（启动快）；「设置」页提供 开始解密 / 增量更新 / 刷新数据库 / 重新解密 / 清除缓存 五种操作，缓存复用 + 增量更新保证聊天有更新时秒级刷新
- **联系人统计**：`contacts_stats()` 对每个联系人统计消息数 / 语音数 / 图片数，以列表展示
- **跨分片读取**：消息库按 `message_N.db` 分片，以 `sort_seq` 键集分页、跨分片合并排序，长会话浏览依然流畅
- **消息内容解码**：兼容明文文本、zstd 压缩 XML、hex/base64 包裹的二进制；图片 md5 从 `packed_info_data`（protobuf）与 XML **双通道**提取，提高命中率
- **联系人名**：备注 > 昵称 > 账号名；群聊消息按「发送者:\n正文」拆分并映射到联系人
- **图片解密**：V2 加密容器（文件头 `07085632`）用 `image_aes_key`（AES-ECB）+ `image_xor_key`（尾部 XOR）还原；老式文件按魔数反推 XOR
- **表情解密**：内置文字表情码 → `static/wxemoji/` 图标；自定义表情本地缓存（`cache/{Emoticon|emoticon|Emoji|emoji}/{md5[:2]}/{md5}.gif|webp|png|dat`）优先，缺失时按消息 XML 的 URL + aes_key 用 **AES-128-CBC（key=iv=aes_key 16B hex，PKCS7）** 远程解密，`.dat` 走图片魔数还原，另以 `emoticon.db`（`kNonStoreEmoticonTable`）兜底
- **语音**：SILK → WAV 由 `pysilk`（silk-python，含本地 CFFI/Cython 二进制）完成，全程本地计算
- **头像**：单聊按对方 `username`、群聊按消息正文里的 wxid 关联到 `head_image.db`；**本账号头像自动从微信数据目录还原**（无需手动填写），保证 HTML 归档完整
- **输出实时性**：exe 启动脚本对 `stdout/stderr` 启用**行缓冲**，所有提示与进度实时刷新到控制台

A：这是软件的**一次性授权激活**机制（未激活时无法使用核心功能）。输入当天有效的 16 位授权码（`XXXX-XXXX-XXXX-XXXX`）即可激活；激活成功后软件会在缓存目录 `important/` 写入硬件绑定激活文件，之后本机自动免激活直接运行。授权码每日变化，请联系**技术支持 v：dawn10370108** 获取。

**Q：如何获取数据库密钥？**
A：在左侧边栏「获取密钥」视图：方式一点「一键获取密钥」（V4 内存扫描，无需重新登录）；方式二点「开始注入」（Hook 注入），注入后退出并重新登录微信，即可在登录瞬间截获密钥。获取成功自动写入 `config.ini`。

**Q：打开导出页面后没有聊天消息，只有联系人列表？**
A：这是新版**按需解密**设计：默认只解密联系人列表、不解密消息（启动更快）。请到「设置」视图点「开始解密」，完成后即可浏览与导出聊天记录。

**Q：聊天有新消息了，但导出页面看不到？**
A：每次启动会沿用 `cache/` 里的解密缓存（源库未变则直接复用）。若源库有变化，到「设置」视图点「增量更新」即可，无需重新全量解密。

**Q：想重新解密或清空缓存？**
A：「设置」→「解密管理」提供五种操作：开始解密 / 增量更新 / 刷新数据库 / 重新解密 / 清除缓存。

**Q：导出 HTML 里头像显示不出来 / 是破碎占位？**
A：这是旧版 `exporters.py` 的嵌套 `<img>` 缺陷（`<img src="<img .../>">`），已修复为正确的自闭合 `<img>`。本账号头像已改为**自动从微信数据目录还原**（无需手动填写），通常不会再缺失。

**Q：找不到数据库 / 提示未找到微信进程？**
A：确认微信已登录、聊天记录保存在本地，并核对 `config.ini` 的 `data_dir`（获取密钥视图会自动写入）。

**Q：导出网页打不开？**
A：确认 `TalkBook-导出.exe` 所在目录可写（它要在同目录生成 `cache/`、`exports/`）；或改用 `--port` 指定一个空闲端口。

**Q：语音播放不出来？**
A：确认微信数据目录可访问（语音从 `media_N.db` 读取）。exe 已内置 pysilk 解码二进制，源码运行请先 `uv sync`。

**Q：语音转文字为什么提示没有待转写的语音？**
A：确认目标路径正确（单个 `.html` 或含归档子目录的文件夹），且该归档的 `media/` 下有对应 wav 文件；已含 `asr-text` 标记的语音会自动跳过（断点续跑）。

**Q：语音转文字转不动 / 一直失败？**
A：语音转文字需要联网调用你配置的大模型接口。请在「语音转文字」视图或 `config.ini` 的 `[ASR]` 段填好 `api_url` / `api_key` / `model`，并确认网络可达、密钥有效、模型支持音频转写。

## 隐私与安全

- 所有解密、解析、导出均在**本机**完成，不向任何外部网络发送数据
- **语音转文字**例外：该功能会把语音文件发送到你自行配置的 `[ASR] api_url` 大模型接口进行转写；若在意隐私，请勿开启或使用本地/受信任的接口
- 密钥与聊天内容**不落盘到微信账号目录**，只存在于本程序目录的 `config.ini` 与导出文件中
- 请妥善保管 `config.ini`（含密钥）与导出文件，勿外传
- 本工具仅用于备份/查阅**自己设备上的聊天记录**，请遵守微信用户协议与当地法律法规

## 已知限制

- **图片**：若某账号从未产生过 V2 图片（kvcomm 无码或模板缺失），该图片显示 `[图片]` 占位
- **表情/视频/文件**：内置文字表情码与自定义表情已完整支持（见上文「表情解密」）；但**自定义表情若既无本地缓存、又无法访问其远程 CDN 地址**（离线 / 链接失效），仍会显示 `[表情未下载]` 占位；视频/文件消息可识别并渲染为占位，不下载原文件
- 方式二 Hook 的兼容性取决于 `wx_key.dll` 与微信版本的匹配程度，若截获不到请换用方式一
